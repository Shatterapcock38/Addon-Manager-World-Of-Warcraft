## ⚙️ **Detailed Features**

### **📦 Addon Management**
- **Single Window Control** – Manage all addons from one interface
- **Smart Search** – Find addons by name, description, or custom keywords
- **Custom Categories** – 8 functional groups + manual assignment
- **Class Rules** – 13 Retail classes (9 on WoW Forever) with per-class toggles
- **Native Settings** – One-click access to supported addon options
- **Child Addon Control** – Independent toggles for companion packages
- **Recommended Presets** – Tested configurations for first-time installs

### **🎮 Load Modes**
Four independent configurations for different playstyles:
- **Mythic+** – Dungeon-specific loadouts
- **Raid** – Raid-focused addon sets
- **PvP** – Battleground/Arena configurations
- **Global** – Everyday addon presets

Features:
- Double-click to switch modes
- Temporary session overrides
- Automatic UI reload
- Protected dependencies respected
